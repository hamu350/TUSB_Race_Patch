# TheUnusualSkyBlock Race_Patch
## 概要
TUSB_RPとはTUSB_v12Rの世界で、攻略・PKなどで変動するレースポイントを誰よりも多く集めることが目的になるミニゲームパッチです。

## 導入方法
1. Releasesから最新版をDLする
2. 「TheUnusualSkyBlock_v12Remake\datapacks」に「z_TUSB_Race_Patch.zip」を入れてください
3. 導入完了です

## 主な変更点
- 職業島から9つの初期地点を選択可能に
- 固定の初期装備
- 経験値バーをMPバーに
- レースポイントの実装
- エンドポータルフレームの増加
- シフトメニュー・タイマーシステムをTUSB_TLEから移植
- スキルを当てるシステムをTUSB_PvPから移植
- プレイヤーを常に発光
- テーブルマウンテンを持ち込み可能に

```
### ポイント変動条件
通常世界攻略　　　　　: +3
別ディメンション攻略　: +20
擬態スポナー破壊　　　: +1
黒曜石スポナー破壊　　: +3
Adv.スポナー       　: +1
死亡時　　　　　　　　: -10
```

## 注意点
- この作品の一部はTUSB_TLEとTUSB_PvPのデータパックが移植されています。
- 基本的な仕様はTUSB_v12Rと同じため、以下のようなプレイが戦略として用いられる可能性があります。そのため、事前にプレイヤー同士で話し合うことを推奨します。<br>
　・無敵である村人をロストオブライブズで倒す<br>
　・煉獄ポータルフレームの複製元にエンダーアイをはめる<br>
　・サーバーを意図的に重くする　など
